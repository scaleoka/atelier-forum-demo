# Atelier — форумный прототип

Atelier — интерактивный прототип форума на HTML, CSS и JavaScript. Чтобы открыть демонстрацию, скачайте `index.html` и откройте его в браузере. Установка зависимостей не требуется.

В демо можно открыть раздел форума и тему, добавить ответ, процитировать сообщение и настроить оформление. Добавленные сообщения и настройки сохраняются локально в браузере. Стартовое содержимое служит для демонстрации интерфейса.

Прототип работает без сервера и аккаунтов. Разделы личного пространства демонстрируют навигацию и интерфейс.
